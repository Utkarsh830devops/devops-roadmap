How to show gap as experience
================================

2023 & 2024 Passedout => Fresher Resume

2022 Passedout => 2.5 years gap => 2.5 yrs exp

2021 Passedout => 3.5 Years gap => 3.5 yrs exp

2020 Passedout => 4.5 years gap => 4 yrs exp

2019 Passedout => 5.5 years gap => 4 yrs exp + 1 yr training

2018 passedout => 6.5 years gap => 4 yrs exp + 2.5 yrs non IT exp

========================================================

=> First thing we need to check is our official email inbox

=> If required we need to provide replies for those emails.

=> Check meetings scheduled for today and get ready for those meetings

=> Check JIRA dashboard and work on the tasks which are assinged on your name.

=> Join daily scrum calls and give work updates to scrum master

        - working which story

        - when it will be completed

        - any challenges to complete it 

        - any help required

        - any blockers


Note: If you are not able to join scrum call for today then send work updates to scrum master in email.
